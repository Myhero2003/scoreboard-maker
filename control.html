背景・キャンバス

背景画像は data URL として localStorage に保存されます。巨大な画像は保存容量(約 5MB)を超えて失敗することがあるため、 配信解像度に合わせて事前に縮小しておくことを推奨します。

要素ごとの表示設定

連動 ON の間は フォント / 色 / 縁取り / 縁取り色 / 横幅 が左右で同期します(位置とサイズは除く)。

Google スプレッドシート連携(Apps Script)

同期は停止中です。

同期 ON の間は 7 秒ごとにシートを取得し、取得できた項目 (p1name / p2name / p1score / p2score / round / bo)を上書きします。 スタイルや位置は同期対象外です。ローカル操作と競合した場合は直近に取得したシートの値が優先されるため、 手元だけで操作したいときは同期を OFF にしてください。

Apps Script サンプルコードとシート構成を表示

シート「Scoreboard」の 1 行目をヘッダー、2 行目を値とする横 1 行構成: 

| A       | B       | C       | D       | E       | F   |
| p1name  | p2name  | p1score | p2score | round   | bo  |
| Player1 | Player2 | 2       | 1       | ROUND 1 | BO3 |
/**
 * Google Apps Script: スコアボード用 JSON エンドポイント
 *
 * 使い方:
 *   1. 対象のスプレッドシートを開き、[拡張機能] > [Apps Script] を選択
 *   2. このコードを貼り付けて保存
 *   3. [デプロイ] > [新しいデプロイ] > 種類「ウェブアプリ」
 *      - 次のユーザーとして実行: 自分
 *      - アクセスできるユーザー: 全員
 *   4. 発行された /exec で終わる URL を control.html の入力欄に貼る
 *
 * 【重要・セキュリティ注意】
 *   「アクセスできるユーザー: 全員」で公開した場合、URL を知っている人は
 *   誰でもこのエンドポイントにアクセスでき、シートの内容(プレイヤー名や
 *   スコア)を読み取れます。URL が漏れると意図しない第三者に閲覧される
 *   可能性があるため、URL は配信画面や公開リポジトリに映さないでください。
 *   また、シート自体の編集権限を渡した協力者は当然スコアを書き換えられます。
 *   機密情報はこのシートに置かないこと。
 */
var SHEET_NAME = 'Scoreboard';

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName(SHEET_NAME);
  var values = sheet.getDataRange().getValues();
  var headers = values[0];   // 1 行目 = カラム名
  var row = values[1] || []; // 2 行目 = 現在の値

  var out = {};
  for (var i = 0; i < headers.length; i++) {
    var key = String(headers[i]).trim();
    if (!key) continue;
    out[key] = row[i];
  }
  out.updatedAt = new Date().toISOString();

  return ContentService
    .createTextOutput(JSON.stringify(out))
    .setMimeType(ContentService.MimeType.JSON);
}

OBS 設定メモ

1. OBS に display.html をブラウザソースとして追加(幅・高さはキャンバス設定と同じ値に)。これが配信に映る本体です。
2. OBS に control.html もブラウザソースとして追加しますが、配信シーンには含めないでください (専用の非表示シーンに置くか、ソース一覧で目玉アイコンを OFF にする)。
3. 両方を OBS 内のブラウザソースとして追加することで、同じ localStorage を共有し自動的に同期されます。
4. control.html を操作するときは、そのソースを右クリック →「操作(Interact)」で開きます。
